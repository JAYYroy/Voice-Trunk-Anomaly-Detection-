## 1. Probabilistic Modeling via Gaussian Mixture Models (GMM)

In pattern recognition, real-world network traffic does not conform to a single unimodal Gaussian distribution due to diverse transmission routing paths (e.g. local loop vs transcontinental peering links). A **Gaussian Mixture Model (GMM)** is a parametric probability density function represented as a weighted sum of $K$ multivariate Gaussian component densities.

For a feature vector $\mathbf{x} \in \mathbb{R}^D$ (where $D=6$ in our system), the probability density function is defined as:

$$p(\mathbf{x} \mid \boldsymbol{\theta}) = \sum_{k=1}^K \pi_k \, \mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)$$

Where:
- $\boldsymbol{\theta} = \{\pi_k, \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k\}_{k=1}^K$ is the set of all model parameters.
- $\pi_k$ represents the **mixture weight** (prior probability) of component $k$, satisfying:
  $$\sum_{k=1}^K \pi_k = 1 \quad \text{and} \quad 0 \le \pi_k \le 1$$
- $\boldsymbol{\mu}_k \in \mathbb{R}^D$ is the mean vector of the $k$-th Gaussian component.
- $\boldsymbol{\Sigma}_k \in \mathbb{R}^{D \times D}$ is the symmetric positive-definite covariance matrix of the $k$-th component.

The multivariate normal density $\mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)$ is expressed as:

$$\mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k) = \frac{1}{(2\pi)^{D/2} |\boldsymbol{\Sigma}_k|^{1/2}} \exp \left( -\frac{1}{2} (\mathbf{x} - \boldsymbol{\mu}_k)^T \boldsymbol{\Sigma}_k^{-1} (\mathbf{x} - \boldsymbol{\mu}_k) \right)$$

By selecting `covariance_type="full"`, each component learns independent pairwise feature covariances, capturing the joint correlation between latency spikes and jitter fluctuations.

## 2. Parameter Estimation: The Expectation-Maximization (EM) Algorithm

Because the assignment of observations to Gaussian components is an unobserved latent variable $z \in \{1, \dots, K\}$, standard maximum likelihood estimation cannot be solved in closed form. Instead, the **Expectation-Maximization (EM)** algorithm is employed iteratively.

Given a baseline training dataset $\mathbf{X} = \{\mathbf{x}_1, \dots, \mathbf{x}_N\}$ of $N$ normal observations, the goal is to maximize the incomplete log-likelihood:

$$\ln L(\boldsymbol{\theta}) = \sum_{n=1}^N \ln \left( \sum_{k=1}^K \pi_k \, \mathcal{N}(\mathbf{x}_n \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k) \right)$$

### 2.1 Expectation Step (E-step)
Using the current estimate of parameters $\boldsymbol{\theta}^{(t)}$, compute the **responsibility** $\gamma_{nk}$, which represents the posterior probability that observation $\mathbf{x}_n$ was generated by component $k$:

$$\gamma_{nk} = P(z_n = k \mid \mathbf{x}_n, \boldsymbol{\theta}^{(t)}) = \frac{\pi_k^{(t)} \mathcal{N}(\mathbf{x}_n \mid \boldsymbol{\mu}_k^{(t)}, \boldsymbol{\Sigma}_k^{(t)})}{\sum_{j=1}^K \pi_j^{(t)} \mathcal{N}(\mathbf{x}_n \mid \boldsymbol{\mu}_j^{(t)}, \boldsymbol{\Sigma}_j^{(t)})}$$

### 2.2 Maximization Step (M-step)
Update the parameters $\boldsymbol{\theta}^{(t+1)}$ using the computed responsibilities:

1. **Effective number of points assigned to component $k$:**
   $$N_k = \sum_{n=1}^N \gamma_{nk}$$

2. **Updated Mixture Weights:**
   $$\pi_k^{(t+1)} = \frac{N_k}{N}$$

3. **Updated Mean Vectors:**
   $$\boldsymbol{\mu}_k^{(t+1)} = \frac{1}{N_k} \sum_{n=1}^N \gamma_{nk} \mathbf{x}_n$$

4. **Updated Covariance Matrices:**
   $$\boldsymbol{\Sigma}_k^{(t+1)} = \frac{1}{N_k} \sum_{n=1}^N \gamma_{nk} (\mathbf{x}_n - \boldsymbol{\mu}_k^{(t+1)}) (\mathbf{x}_n - \boldsymbol{\mu}_k^{(t+1)})^T$$

The E and M steps iterate until the increase in log-likelihood falls below a convergence tolerance ($\epsilon = 10^{-3}$).

## 3. Model Selection: AIC & BIC Formulations

Selecting the optimal number of Gaussian components $K$ prevents underfitting (failing to capture complex routing modalities) or overfitting (modeling noise). We evaluate two statistical information criteria across $K \in \{1, 2, 3, 4, 5\}$:

### 3.1 Bayesian Information Criterion (BIC)
$$\text{BIC} = -2 \ln \hat{L} + p \ln(N)$$

### 3.2 Akaike Information Criterion (AIC)
$$\text{AIC} = -2 \ln \hat{L} + 2p$$

Where:
- $\hat{L} = \prod_{n=1}^N p(\mathbf{x}_n \mid \hat{\boldsymbol{\theta}})$ is the maximized likelihood.
- $N$ is the total number of training samples ($N = 9,195$ baseline observations).
- $p$ is the total number of independent parameters for full covariance matrices:
  $$p = (K - 1) + K \cdot D + K \cdot \frac{D(D + 1)}{2}$$
  For $D = 6$, each component adds $1 + 6 + 21 = 28$ parameters.

**Selection Criterion:** The model configuration that minimizes the BIC is selected as the optimal model. Because BIC penalizes parameter complexity by $\ln(N)$ rather than $2$, it strongly resists overfitting in large telemetry datasets.

## 4. Anomaly Scoring & Mathematical Justification

In unsupervised anomaly detection, an anomaly is defined as an observation that occurs in a region of low probability density under the model learned from normal operational data.

For an incoming observation $\mathbf{x}$, the GMM computes its log-likelihood via `score_samples()`:

$$\text{LL}(\mathbf{x}) = \ln p(\mathbf{x} \mid \boldsymbol{\theta}) = \ln \left( \sum_{k=1}^K \pi_k \mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k) \right)$$

Because probabilities satisfy $0 \le p(\mathbf{x}) \le 1$, the log-likelihood is non-positive: $\ln p(\mathbf{x}) \le 0$. As an observation moves further into the multi-dimensional tail of the distribution, $p(\mathbf{x}) \to 0$ and $\ln p(\mathbf{x}) \to -\infty$.

To provide an intuitive, monotonically increasing score, we define the **Anomaly Score** $S(\mathbf{x})$ as the negative log-likelihood:

$$S(\mathbf{x}) = -\ln p(\mathbf{x} \mid \boldsymbol{\theta})$$

- **Normal Telemetry:** High density $\implies$ high likelihood $\implies$ **Low Anomaly Score**.
- **Network Degradation (Loss/Latency Spikes):** Low density $\implies$ near-zero likelihood $\implies$ **High Anomaly Score**.

---

## 5. Dual Percentile Threshold Calibration

Rather than choosing arbitrary heuristic thresholds, our system establishes decision boundaries statistically from the empirical cumulative distribution function (CDF) of anomaly scores evaluated on the normal training baseline:

$$\tau_p = F^{-1}_{S_{\text{train}}}(p/100)$$

Specifically:
1. **Suspicious Threshold ($\tau_{95}$):** The 95th percentile of normal baseline scores.
   $$S(\mathbf{x}) \le \tau_{95} \implies \text{NORMAL}$$
2. **Critical Anomaly Threshold ($\tau_{99}$):** The 99th percentile of normal baseline scores.
   $$\tau_{95} < S(\mathbf{x}) \le \tau_{99} \implies \text{SUSPICIOUS}$$
   $$S(\mathbf{x}) > \tau_{99} \implies \text{ANOMALOUS}$$

This principled design guarantees an expected baseline false alert rate of no more than $1\%$ during steady-state operations, while maintaining $100\%$ sensitivity to catastrophic QoS degradations.
